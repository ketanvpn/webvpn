# KETANTECH VPN - Future Development Roadmap

Dokumen ini mencatat ide-ide brilian untuk pengembangan sistem KETANTECH VPN di masa mendatang agar bisnis semakin berkembang dan operasional semakin efisien.

## 1. Fitur Marketing & Penjualan (Meningkatkan Omzet)
- [x] **Sistem Kode Promo / Voucher:** 
  Pembuatan kode diskon (misal: `RAMADHAN20` atau `DISKONKILAT`) dengan batas kuota/waktu. Ini digunakan saat *campaign* marketing untuk menarik pengguna baru membeli VPN. ✅ **Selesai**
- [x] **Sistem Poin / Loyalty Reward:** 
  Setiap pengguna melakukan topup atau order, mereka mendapat Poin. Poin ini dapat ditukar menjadi saldo atau diskon khusus. Berfungsi untuk menjaga loyalitas pelanggan (retensi). ✅ **Selesai**
- [x] **Popup Pengumuman di Dashboard User:** 
  Banner popup saat user login, sangat berguna untuk pengumuman *maintenance* atau promosi mendadak. ✅ **Selesai**

## 2. Kemudahan Operasional Admin (Efisiensi Waktu)
- [x] **Ekspor Laporan Keuangan (Excel / PDF):** 
  Fitur di halaman Topup/Transaksi untuk merekapitulasi data pemasukan per bulan ke format CSV, memudahkan proses pembukuan. ✅ **Selesai**
- [x] **Aksi Massal (Bulk Actions):** 
  Memberikan opsi *checkbox* di daftar akun VPN dan user untuk memproses puluhan akun sekaligus (misal: hapus masal akun kedaluwarsa, atau aktifkan masal). ✅ **Selesai**

## 3. Pemantauan Infrastruktur Tingkat Lanjut (Monitoring)
- [x] **Live Server Monitor (CPU/RAM):** 
  Tampilan grafik *real-time* di panel Admin yang memonitor kesehatan server (penggunaan RAM, CPU, Kapasitas Disk) dari setiap mesin VPS yang didaftarkan. ✅ **Selesai**
- [x] **Auto-Disable Server Penuh:** 
  Otomatisasi untuk menyembunyikan Server dari daftar pilihan pembelian jika server tersebut telah mencapai batas kuota maksimal koneksi/pengguna. ✅ **Selesai**

## 4. Bantuan & Interaksi Otomatis (Customer Support)
- [x] **Fitur Live Chat / Tiket Bantuan:** 
  Sistem tiket bawaan aplikasi di mana pengguna bisa mengirim pesan bantuan dan Admin membalas langsung melalui dashboard (tanpa perlu via WA), menjadikan riwayat keluhan tertata rapi. ✅ **Selesai**
